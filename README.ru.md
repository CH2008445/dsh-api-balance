# dsh-api-balance

**Баланс API DeepSeek и расход за текущий запуск** для веб-интерфейса [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Одна строка в нижней части боковой панели показывает баланс и то, сколько стоил текущий запуск.

Плагин решает одну задачу: показывать расходы, **не расширяя область доступа к вашему API-ключу**. Весь плагин — четыре небольших файла, которые можно прочитать за несколько минут.

[English](README.md) | [中文](README.zh.md) | [Deutsch](README.de.md)

## Зачем это нужно

Плагин DSH работает в том же процессе, что и ваш API-ключ. Границы доступа между плагином и хранилищем учётных данных нет, поэтому любой плагин может получить ключ в открытом виде. Что ещё делает плагин баланса с этим ключом, определяется исключительно его кодом — и ничто этого за вас не проверяет.

Некоторые существующие плагины баланса идут на излишний риск:

| Рискованная практика | Почему это важно |
|---|---|
| Подстановка ключа в команду оболочки | Ключ попадает в аргументы дочернего процесса и доступен любому процессу через список процессов |
| Запуск `curl` с отключённой песочницей | Для одного GET-запроса `danger-full-access` не нужен никогда |
| Отправка ключа на любой заданный `baseURL` | Опечатка или вредоносное зеркало уводит ключ |
| Локальный HTTP-эндпоинт без проверки источника | Любой локальный процесс или веб-страница может прочитать данные вашего аккаунта |

Этот плагин не делает ничего из перечисленного, и проверки релиза следят за тем, чтобы это не появилось снова.

## Что он делает

- Получает `DEEPSEEK_API_KEY` через хранилище учётных данных DSH на стороне хоста
- Запрашивает `GET https://api.deepseek.com/user/balance` встроенным `fetch`
- Считает стоимость каждого вызова модели по данным об использовании, которые harness выдаёт для каждого запроса, по официальным ценам в юанях с учётом пикового и непикового тарифов
- Отдаёт баланс, итоги по токенам, стоимость и таблицу цен, а в интерфейсе рисует одну строку в `sidebar.footer.action`

Строка выглядит так: `Balance ¥6.39  ·  Cost ¥0.12` — баланс и стоимость с начала запуска процесса, каждая величина подписана. Обе показываются всегда: неизвестное значение сохраняет прочерк `--`, а не исчезает, поэтому строка не смещается после первого платного вызова.

При наведении открывается подсказка, которая **начинается с таблицы цен**: ставки каждой модели за 1 млн токенов для обоих тарифов с пометкой действующего, а затем идут баланс, стоимость запуска и разбивка по токенам. Цены стоят первыми, чтобы раньше увидеть ставки, из которых выведена стоимость. Щелчок обновляет данные.

## Учёт стоимости

Стоимость выводится из блока использования, который harness выдаёт на каждый вызов модели, поэтому она отражает фактически сделанные запросы, включая повторы. Итоги относятся к текущему запуску процесса и сохраняются на диск, так что перезагрузка плагина не сбрасывает цифру; новый запуск начинается с нуля.

Цены взяты со [страницы официальных цен](https://api-docs.deepseek.com/quick_start/pricing), в юанях за 1 млн токенов:

| Модель | Тариф | Попадание в кеш | Промах кеша | Вывод |
|---|---|---|---|---|
| `deepseek-flash` | непиковый | 0.02 | 1 | 4 |
| `deepseek-flash` | пиковый | 0.04 | 2 | 8 |
| `deepseek-v4-pro` | непиковый | 0.15 | 4.5 | 13.5 |
| `deepseek-v4-pro` | пиковый | 0.30 | 9.0 | 27.0 |

Применяемые правила:

- **Пиковые часы** — по пекинскому времени (UTC+8), понедельник–пятница, 09:00–12:00 и 14:00–18:00. Всё остальное время, включая выходные, — непиковый тариф.
- **Запись в кеш тарифицируется по цене попадания**, как исторически у DeepSeek.
- **Снятые с обслуживания имена считаются по модели, которая их обслуживает**: `deepseek-v4-flash` и `deepseek-v4-flash-vision-exp` — по ценам `deepseek-flash`.
- **Неизвестная модель стоит ноль**, а не угаданную цену.

Две вещи нельзя вывести автоматически, поэтому они задаются конфигурацией: **календарь государственных праздников Китая** (в эти дни будни считаются непиковыми) и изменение цен.

## Безопасность

| Ограничение | Как обеспечено |
|---|---|
| Ключ не покидает процесс хоста | Читается через `ctx.credentials.resolve()`; не попадает ни в ответ, ни в лог, ни в браузер |
| Ключ не попадает в командную строку | Только встроенный `fetch` — без дочерних процессов и оболочки. Проверяется в проверках релиза |
| Песочница не обходится | Плагин не читает и не изменяет политику песочницы. Проверяется в проверках релиза |
| Ключ отправляется только в DeepSeek | Хост эндпоинта обязан быть `api.deepseek.com`, иначе плагин откажется отправлять ключ. Не настраивается |
| Эндпоинт недоступен для межсайтовых запросов | Требуется заголовок `x-dsh-balance: 1` (нестандартный заголовок вызывает предварительный запрос CORS) и проверяется `Origin` на петлевой адрес |
| Ошибки ничего не раскрывают | Сетевые, разборочные и HTTP-ошибки возвращают одну фиксированную формулировку, никогда — исходную ошибку |
| Запросы не размножаются | Успешные чтения баланса кешируются; неудачные не кешируются никогда |

Эндпоинт и работа с учётными данными — **инварианты безопасности и намеренно не являются настройками**. Настраиваются только поля из раздела «Настройка».

## Требования

- DeepSeek Harness с веб-клиентом (активен набор `dsh-web-app`)
- Ключ DeepSeek API, настроенный как учётные данные `DEEPSEEK_API_KEY` (Настройки → Модели) или экспортированный под этим именем
- Маршрут провайдера `deepseek-official`. **Эндпоинт баланса работает только с официальным адресом**: если ваш `baseURL` указывает на шлюз или зеркало, плагин откажется отправлять ключ, а не раскроет его. Учёт стоимости продолжает работать, так как ему сеть не нужна.

## Установка

### Из локальной копии

```sh
dsh plugin --profile desktop add /path/to/dsh-api-balance
```

CLI DSH подключит пакет к профилю и добавит его в `dsh.profile.bundles`, так как пакет объявляет `dsh.bundle`.

Установка в профиль **не требует разрешения на выполнение кода во время установки**: пакет поставляет готовый каталог `lib/` и не объявляет скрипт `prepare`, поэтому pnpm не запрашивает `allowBuilds`.

### Ручная установка

Добавьте зависимость и строку набора в `$DSH_HOME/profiles/<profile>/package.json`, затем выполните `pnpm install` в каталоге профиля:

```json
{
  "dependencies": { "dsh-api-balance": "file:/path/to/dsh-api-balance" },
  "dsh": {
    "profile": {
      "bundles": [
        "@deepseek-ai/dsh-base",
        "@deepseek-ai/dsh-web-app",
        "dsh-api-balance"
      ]
    }
  }
}
```

Перезапустите DSH. Строка появится в нижней части левой боковой панели.

### Если пакет не материализуется

`pnpm` может сообщить `Already up to date` и при этом не создать `node_modules/dsh-api-balance`, если устаревший импортёр в файле блокировки считает зависимость удовлетворённой. Проверьте, что реально появилось:

```sh
ls "$DSH_HOME/profiles/<profile>/node_modules/dsh-api-balance/lib"
```

Если каталога `lib/` нет, свяжите запись профиля с вашей рабочей копией. В Windows:

```bat
mklink /J "%USERPROFILE%\.dsh\profiles\desktop\node_modules\dsh-api-balance" "C:\path\to\dsh-api-balance"
```

В macOS или Linux:

```sh
ln -s /path/to/dsh-api-balance "$HOME/.dsh/profiles/desktop/node_modules/dsh-api-balance"
```

У символической ссылки есть и второе преимущество при разработке: правки в рабочей копии действуют без переустановки. Обратная сторона — `pnpm install` в этом профиле может заменить ссылку, поэтому при пропаже пакета создайте её снова.

### Проверка установки

Откройте консоль браузера в интерфейсе и выполните:

```js
fetch('/api/dsh-api-balance', { headers: { 'x-dsh-balance': '1' } }).then(r => r.json()).then(console.log)
```

Объект `{ ok: true, currency: "CNY", totalBalance: "...", prices: { ... } }` означает, что хостовая часть работает. `404` означает, что строка загрузчика не активировалась; `403` — что запрос дошёл до маршрута без нужного заголовка или из другого источника.

## Диагностика

### Строка отображается, но пишет `Balance unavailable`

Наведите курсор на строку или выполните фрагмент выше, чтобы прочитать причину. `HTTP 404` означает, что хостовая часть не зарегистрировала маршрут: это сбой активации, а не проблема с ключом. Проверьте журнал активации.

### Журнал активации

Плагин дописывает шаги активации в `dsh-api-balance/plugin.log` внутри временного каталога пользователя (`%TEMP%` в Windows, `$TMPDIR` в других системах). Переменная `DSH_BALANCE_DIAG=<dir>` перенаправляет запись. Исправная активация оставляет четыре строки:

```
module evaluated (exports: name=api-balance, apply=function)
apply() entered; config={}
inject callback fired
webServer resolved: function
```

Журнал существует потому, что сбой активации иначе невидим: плагин по-прежнему рисует свою строку, ничего не добавляя, и ни один системный журнал об этом не сообщает.

| Содержимое журнала | Значение |
|---|---|
| Файла нет | Загрузчик не импортировал модуль: строка набора не разрешилась |
| Только `module evaluated` | Модуль загрузился, но фреймворк его не принял. Сначала проверьте экспорт `Config`: Cordis требует, чтобы присутствующий `Config` реализовывал Standard Schema (`Config["~standard"].validate`), и прерывает активацию, если это не так |
| `apply() entered` без `inject callback fired` | Объявленная зависимость так и не появилась, поэтому маршрут не зарегистрирован |
| Все четыре строки | Активация в порядке; причина в запросе или в учётных данных |

Журнал содержит только имена сервисов, результаты разрешения и коды состояния. API-ключа в нём нет никогда.

### Ловушка с экспортом `Config`

Плагин экспортирует `Config` только тогда, когда `@deepseek-ai/schemastery` разрешается **и** его результат реализует Standard Schema. Экспортировать схему, которая не может проверить конфигурацию, хуже, чем не экспортировать ничего: Cordis вызывает `Config["~standard"].validate(config)` до `apply`, и это исключение убирает все вклады плагина, оставляя интерфейс на месте. Плагин, который рисует, но ничего не делает, почти всегда страдает именно этим.

## Настройка

Необязательно, в `cordis.yml`/`cordis.patch.yml` профиля:

```yaml
- id: api-balance
  name: dsh-api-balance
  config:
    cacheMs: 60000
    path: /api/dsh-api-balance
    persistUsage: true
    holidays:
      - '2026-10-01'
      - '2026-10-02'
    prices:
      deepseek-flash:
        cacheHit: 0.02
        cacheMiss: 1
        output: 4
        peak:
          cacheHit: 0.04
          cacheMiss: 2
          output: 8
```

| Поле | По умолчанию | Значение |
|---|---|---|
| `cacheMs` | `60000` | Время жизни кешированного чтения баланса в миллисекундах (0 – 3600000) |
| `path` | `/api/dsh-api-balance` | Точный HTTP-маршрут, отдающий данные |
| `persistUsage` | `true` | Сохранять итоги использования, чтобы перезагрузка плагина не теряла расход запуска |
| `holidays` | `[]` | Пекинские праздничные даты (`YYYY-MM-DD`), тарифицируемые как непиковые |
| `prices` | встроенные | Замена или расширение таблицы цен, юани за 1 млн токенов |

Итоги использования хранятся в `$DSH_HOME/storages/api-balance/usage.json`.

## Разработка

Шага сборки нет: файлы в `lib/` — это и есть поставляемые артефакты. `lib/client.js` — написанный вручную набор в формате DSH `window.__ModuleLoader__`, а `lib/types/index.d.ts` содержит публичные типы.

```sh
node scripts/verify.mjs           # проверки без сети и без учётных данных
BALANCE_TEST_KEY=sk-... node scripts/verify.mjs --live   # плюс один реальный запрос
```

`scripts/verify.mjs` проверяет контракт манифеста, патч загрузчика, набор экспортов хоста, перечисленные выше инварианты безопасности, арифметику цен и пиковые окна, сохранение журнала учёта, поведение маршрута при отказах, учёт потока, таблицу цен и контракт клиентского набора, а также отрисовку на английском, китайском, русском и немецком. Установка DSH и сеть не нужны, если не передан `--live`.

**Правило идентификатора клиентского набора.** Идентификатор модуля, переданный в `window.__ModuleLoader__.load`, обязан совпадать с именем пакета. Несовпадение заставляет браузерную модульную систему отвергнуть фабрику и проваливает всю запись загрузки с ошибкой `duplicate factory registration`, из-за чего приложение не запускается. `scripts/verify.mjs` проверяет это явно — этот тест нужно сохранять.

## Откат

Удалите `"dsh-api-balance"` из `dsh.profile.bundles` в `package.json` профиля и перезапустите. Если приложение отказывается запускаться, диалог ошибки DSH предлагает **отключить сторонние плагины и перезапустить**, что выполнит это восстановление за вас.

## Ограничения

- Баланс только с официального эндпоинта; `baseURL` шлюзов и зеркал отклоняются по замыслу
- Стоимость охватывает текущий запуск процесса, а не историю предыдущих
- Государственные праздники Китая считаются непиковыми, только если перечислены в `holidays`; официальный календарь нельзя узнать заранее
- Цены встроены и требуют обновления при изменении тарифов DeepSeek
- Показывается только первая запись `balance_infos`
- В свёрнутой панели подписи убираются, остаются только суммы
